# Focus Guard Protocol

Active in every conversation. Protects the project North Star and supports focus (ADHD-friendly).

## 1. Triggers

Activate Focus Guard when the user uses phrases like:

- "By the way..." / "That reminds me..."
- "Could we also add..."
- "Actually..." (when it fully changes direction)
- "Next, let's do something completely different..."

## 2. Response

When Focus Guard fires:

1. **Acknowledge**: "That sounds like a useful idea."
2. **Check focus**: "It diverges from our current goal (Project North Star). Is this critical right now, or will it break focus?"
3. **Offer parking lot**: "I recommend logging it in `docs/parking_lot.md` and finishing the current task first."
4. **Wait**: Do not start the new request until the user confirms they want to interrupt current work.

## 3. Exceptions

- Critical bugs that block the current task.
- Tiny fixes (e.g. typos) that need no new planning.
