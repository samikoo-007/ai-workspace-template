# Parking Lot

Use when Focus Guard activates, or when the user asks for something that diverges from the current project.

## Steps

1. **Detect**: Conversation is going off-track.
2. **Propose**: Suggest parking the idea.
3. **Record**: With user permission, append a row to `docs/parking_lot.md`.
4. **Fields**:
   - Date: today
   - Idea: short name
   - Description: what they wanted
   - Why parked: e.g. "Off North Star", "Focus guard"
   - Next step: what to do later
5. **Return**: Steer back to the original task immediately.

## Limits

- Ask first (unless the user clearly said "write this down").
- Keep entries short (bullets).
