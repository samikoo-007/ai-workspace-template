# Brändiohjeisto (Brand Design)

Tämä kansio on projektin brändin visuaalisen identiteetin "Single Source of Truth".

Kun tuotat tai muokkaat käyttöliittymiä, tarkista TÄMÄN KANSION alikansiosta `resources/` löytyvät tiedostot ja noudata niissä annettuja sääntöjä.

Käyttäjä voi sijoittaa tänne:
- Väripaletit (esim. `colors.json` tai `styleguide.md`)
- Fonttiohjeet
- Tiedot logoista ja niiden sijainneista (esim. `assets/logo.svg`)

Jos `resources/` -kansiosta ei löydy sääntöjä, jatka UI/UX Pro Max -taidon standardeilla. Muutoin korvaa oletusarvot poikkeuksetta brändin omilla asetuksilla.
