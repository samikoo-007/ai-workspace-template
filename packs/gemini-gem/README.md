# Pack: gemini-gem

Gemini Gem kickstart docs for turning an idea into workspace documents.

## Activate

Read files in this folder, or copy them into `docs/` if you want them in the project tree.

| File | Purpose |
|------|---------|
| `gem_custom_instructions_paste.txt` | Paste into Gem Custom Instructions |
| `gem_install_guide.md` | Install / Knowledge / what not to upload |
| `gem_workspace_kickstart.md` | Usage flow and project types |

Docs refer to “the AI agent” generically (Cursor or similar).
